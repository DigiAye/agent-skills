# Brief format (`state/brief.md`)

Keep it short enough to read in a minute.

```markdown
# Today, <weekday> <date>  (<mode>, updated <HH:MM>)

**First action:** <one concrete next step, e.g. "Review PR #482 for Priya; she's blocked">

## Focus
1. <title> (<source>, <score>), <one-line reason>
2. ...
3. ...

## Waiting on you
- <who> is waiting on <what> since <when>

## Calendar
- 10:00-10:30 <meeting>

## Queue
- <title> (<source>)

## Sources
github: online via gh (12) | jira: online via mcp (7) | outlook: manual | teams: offline

<If demo data: "Demo data. Nothing here is real.">
```

For `refresh`, add a `## Since last refresh` section at the top listing what moved in or out of focus.

For `wrap`, replace the sections with `## Done`, `## Carried over to <next working day>` and `## Still waiting on you`.
