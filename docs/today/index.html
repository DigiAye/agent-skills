Five commands

morning

Gather everything, rank it, and tell you the first thing to do.

refresh

Re-check what changed and say what moved in or out of focus.

wrap

What got done, what carries over, and who's still waiting on you.

explain

Why an item ranks where it does, rule by rule.

doctor

Which sources are connected and how, without fetching any data.

How ranking works

Scores are fixed rules, so explain can always tell you why. The model writes the summary; the maths stays predictable.

Production incident+40
Someone is blocked on you+30
Due today or overdue+25
VIP sender or mention+15
PR waiting, per working day+5
Newsletters and bot noise−20

Sources, with fallbacks

GitHub

GitHub MCP server, or the gh CLI. Review requests, your PRs, notifications.

Jira

Atlassian remote MCP server, or acli with a JQL filter.

Outlook

Microsoft Graph MCP or the m365 CLI. Mail and calendar.

Teams

Same Graph options, or paste mode when your tenant won't allow an app.

Missing a source? It's marked offline and the rest still runs. With nothing connected, today runs on built-in demo data.

The HUD, running on demo data

A single HTML file with no server or build. The skill writes state/focus.js; the HUD reloads it every minute.

Safe by default

  • Read-only. Replies, reactions and ticket moves need your yes, one at a time.
  • Email and chat text is treated as data, never as instructions. The demo data includes a prompt-injection email to prove it.
  • Links and attachments are never opened. State stays on your machine in ~/.today.

Install

git clone https://github.com/DigiAye/agent-skills.git
cd agent-skills && ./install.sh

# then, in Claude Code, Cursor or Kiro
/today morning
